# 📝 Interactive To-Do List Application

A clean, responsive, and interactive To-Do List web application built with vanilla HTML, CSS, and JavaScript.

## ✨ Features

- **Add Tasks**: Add new tasks seamlessly using the input box or by pressing <kbd>Enter</kbd>.
- **Complete Tasks**: Toggle task completion with custom visual checkmarks and strikethrough styling.
- **Delete Tasks**: Remove individual completed or unwanted tasks.
- **Persistent Storage**: Automatically saves your task list state in `localStorage` so tasks persist across page refreshes and browser sessions.
- **Responsive & Modern UI**: Beautiful gradient background with glassmorphism-inspired card design.

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure
- **CSS3**: Responsive styling, custom checkmark pseudo-elements, gradients, flexbox
- **JavaScript (ES6+)**: DOM manipulation, event delegation, LocalStorage API

## 🚀 Getting Started

Simply open `index.html` in your web browser, or serve it using any local development server (like VS Code Live Server).
